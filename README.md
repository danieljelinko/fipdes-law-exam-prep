# FIPDes Law Exam Prep

Study resources and generated working files for FIPDes food law exam preparation.

## Contents

- `00_resources/`: food law slides, notes, extracted markdown, generated slide text/layout data, and supporting scripts.
- `00_resources/*.pdf`: source PDFs kept in the repository.

## Not Committed

Large local recordings and private agent/editor state are intentionally ignored:

- `10_context/`
- `.agents/`
- `.claude/`
- `.codex/`
