# Meat-Free Marketing Debate

- Should a sausage be called a sausage if it contains no meat?
- Should a burger be called a burger if it contains no meat?
- Should a steak be called a steak if it contains no meat?

## MEAT ANALOGS

- Food products not produced from meat but possess texture, mouth feel, taste and nutritional value similar to meat products
- Manufactured from such crops as soybeans, wheat and pea
- Sometimes may contain milk, egg and fungal substrates
