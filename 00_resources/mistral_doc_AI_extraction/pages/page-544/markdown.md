Where can I find passed exam papers?

LIBRARY

You can access past exam papers online. Visit the Library website for information on how to find and access past exam papers for your home campus here.

You can access past papers using your TU Dublin login credentials.

Please note that we only hold papers for the previous five years from 2018 –current year. There are gaps in the past exam papers collection from 2020-2022 due to the COVID-19 pandemic.

When searching use module code = TFCA1402 and an older version of this module = TFFL9007. (Note, the older version is also delivered to FSEH School with slightly different emphasis on questions.)
