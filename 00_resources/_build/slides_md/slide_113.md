### Example of a Recall / Withdrawal Plan

*Source: FSAI Guidance Note 10, Appendix 4, Figure 1.* The plan defines **Roles and Responsibilities** under a **Recall Co-ordinator** reporting to the **Owner / CEO**:

| Function | Key responsibilities |
|---|---|
| **Distribution** | Stop all distribution of questionable material; arrange return of product to collection points; prepare inventory and distribution status (where, when, to whom, quantity) |
| **Production & Quality Assurance** | Prepare batch identification; halt production if related problem; investigate cause; check all records; update incident log |
| **Consumer Affairs** | Prepare response for consumers; answer all consumer enquiries; update contact details |
| **Accounting** | Set up stock reconciliation system to determine cost of recall |
| **Legal Counsel** | Handle legal implications |
| **Public Relations** | Handle all press releases — all media |
| **Technical** | Obtain batch identification and samples; obtain product analysis to determine if pick-up or destruction is necessary; consult with regulatory agencies if a recall is required |
| **Marketing** | Notify sales managers and brokers; arrange for pick-up at retail levels; arrange for proper credit to be given |
| **Regional Sales Managers** | Aid in contacting customers; assist in product pick-up and delivery of credit notes |
